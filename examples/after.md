# Проверка HTTP-заголовков

Схема запроса — **HTTPS**. Код ответа — **200**.

Результаты относятся к одному сохранённому ответу. Для выводов о приложении нужен контекст страницы.

| Заголовок | Результат | Комментарий |
| --- | --- | --- |
| `Strict-Transport-Security` | Пройдено | Соответствует правилу инструмента. |
| `X-Content-Type-Options` | Пройдено | Соответствует правилу инструмента. |
| `Referrer-Policy` | Пройдено | Соответствует правилу инструмента. |
| `Content-Security-Policy` | Заголовок присутствует | Проверьте директивы вручную с учётом ресурсов страницы. |
