# Проверка HTTP-заголовков

Схема запроса — **HTTPS**. Код ответа — **200**.

Результаты относятся к одному сохранённому ответу. Для выводов о приложении нужен контекст страницы.

| Заголовок | Результат | Комментарий |
| --- | --- | --- |
| `Strict-Transport-Security` | Отсутствует | Для HTTPS проверьте настройку HSTS и положительное значение max-age. |
| `X-Content-Type-Options` | Требует проверки | Укажите nosniff и проверьте корректность Content-Type. |
| `Referrer-Policy` | Требует проверки | Сверьте политику с задачами приложения. Пример базового значения — strict-origin-when-cross-origin. |
| `Content-Security-Policy` | Отсутствует | Для HTML проверьте применимость CSP и подберите директивы под источники страницы. |
